Maille is a personal finance tool built on a strict double-entry ledger. Every
activity is backed by transactions between accounts, movement reconciliation is
explicit, sharing and liability are computed rather than eyeballed, and money can
be labeled by purpose (funds) independently of where it lives (accounts).

It is built for developers who run their own instance against their own Postgres
database, sync bank movements from their own machine, and spend short daily or
weekly sessions reconciling, categorizing, and reviewing their money.

## Why Maille

- **Zero approximation.** The balance, the fund allocation, the shared
  liability, and the reconciled status all derive from the same ledger. If a
  number is on screen, you can trace it to the transactions underneath.
- **The model is visible.** Activities, transactions, movements, accounts, and
  funds are first-class. The interface exposes ledger structure instead of
  hiding it behind summaries.
- **Self-hosted by design.** Your ledger lives in your Postgres database. You
  control the API and UI that read it; external services are limited to the
  authentication and optional workflow providers you configure.

## The daily loop

The primary workflow is a short reconcile–categorize–review cycle:

1. **Import** bank movements through the web UI, or create them individually
   with the CLI.
2. **Reconcile** each movement to the activities that explain it, or record a new
   activity.
3. **Categorize** activities into categories and funds.
4. **Review** balances and fund allocations — every figure is derived from the
   ledger, so what you see is what the model says.
