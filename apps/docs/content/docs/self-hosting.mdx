---
title: Self-hosting
description: Run the Maille API, database, and web UI on your own machine.
---

Maille is self-hosted: you run the API against your own Postgres database, and
the web UI talks to it over GraphQL. This page walks through a local setup from
a clone of the repository.

## Requirements

- [Bun](https://bun.sh) 1.2 or later
- Postgres 17 (a `docker-compose.yaml` is provided for this)
- Google OAuth credentials (currently required at API startup; the UI supports
  email/password and Google sign-in)

## 1. Start the database

From `apps/api`, start the bundled Postgres:

```bash
docker compose up -d
```

This runs a `postgres:17-alpine` container with a `maille` database on
`localhost:5432` (user `postgres`, password `postgres`), persisted in the
`postgres_data` volume.

## 2. Configure the environment

The API validates its environment at startup. Create a `.env` file with:

```bash title=".env"
DATABASE_URL="postgres://postgres:postgres@localhost:5432/maille"
GOOGLE_CLIENT_ID="…"
GOOGLE_CLIENT_SECRET="…"
LOG_LEVEL="info"
```

<Callout>
  The AI workflows (the movement-to-activity assistant) are optional. If `MISTRAL_API_KEY` is
  absent, workflows are simply disabled.
</Callout>

## 3. Run the API

The API compiles to a single binary with Bun, runs database migrations on
startup, and listens on port `3000` by default. GraphQL is served at
`http://localhost:3000/api/graphql`:

```bash
bun run dev        # development, with hot reload and pretty logs
bun run build      # compile dist/server with SKIP_ENV_VALIDATION
```

The API writes its current GraphQL schema to `schema.graphql` when it starts.

## 4. Run the web UI

The web UI is a Vite app that connects to the API you just started:

```bash
cd apps/ui-react
VITE_API_URL=http://localhost:3000/api bun run dev
```

Log in with your Google account, then create your accounts and funds from the
UI — or script the whole thing with the CLI.

## 5. Connect the CLI

The CLI authenticates against your instance and stores its credentials locally:

```bash
cd apps/cli
bun run dev -- login \
  --url http://localhost:3000/api \
  --ui-url http://localhost:5173
```

From there, the CLI covers common resource operations. See the
[CLI reference](/docs/cli).
